In this folder we add our managers, managers are a single purpose class, used as an entity to do opperations 
for various purposes such as data, communcation and video. For example:

1. JsonManager -> used to read and write information into configs (data).

2. Communcation Managers:   
    A. TCPManager -> used for communcation using the TCP protocol.
    B. UDPManager -> used for communcation using the UDP protocol.
    C. SerialManager -> used for communcation using the Serial protocol.

3. VideoManager -> used for managing video streaming and recording.

For more information on the manager design pattern:
https://www.eventhelix.com/design-patterns/manager/
