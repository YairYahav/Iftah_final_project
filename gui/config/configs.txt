In this folder you put your configs, usually a Json file, for example:

1. communation_config.json
    the config used for connection types and ips, ports and the likes.

2. message_data_config.json
    the config used for octavius message data, like pwms and channels.

3.  video_data_config.json
    the config used for gstreamer pipelines for the video and video recordings.

How to add a config?

To add a config to your project:

1. add a json file

2. format it and add your data

3. go to /lib/global/consts/const_strings and add the path to your config
    example:    
        static const String messagesDataConfigPath = "/config/message_data_config.json";


How to read a Json config?

To read configs we have JsonManager that allows us to read and json configs and formats them as a dictionary.
To read a config using JsonManager we need to provide it with a path, thats why we added a const string of our 
path to ConstStrings.

Do note that you might need to assert the type of dictionary to access the data.
